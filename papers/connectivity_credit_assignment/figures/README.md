# Figures

`paper/`
: The exact files that appear in the published paper. Tracked, so the
  manuscript's figures are always recoverable from this repository.

`generated/`
: What the analysis notebooks write when you run them. Not the published
  files — regenerate freely and diff against `paper/`.

Each notebook saves two versions of every figure: `<name>.pdf` with its legend
and `<name>_nl.pdf` without. The paper labels series inline, so the `_nl`
versions are the ones in the manuscript.
